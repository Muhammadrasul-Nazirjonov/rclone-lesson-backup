rclone lesson backup

This is a private, single-user setup of rclone, the open-source file transfer tool. Its owner uses it to back up their own working files from their own computer to their own Google Drive.

It is not a public service: nobody else signs in to it or uses it.

What it does with Google Drive

  • It uses only the drive.file permission, so it can see and change only the files and folders it creates itself. It cannot see any other file in the Drive.
  • It copies files from the owner's computer to the owner's Drive and checks that each copy is complete.
  • It does not share, publish or send files anywhere else.
